# Colaboración / Contributing

Gracias por tu interés en probar este homebrew.

## Reportar errores

Abre un Issue e indica:
- Modelo: Old 3DS / Old 3DS XL / New 3DS / New 3DS XL / 2DS.
- Versión del programa y si se ejecuta desde Homebrew Launcher.
- Pasos exactos para reproducir el fallo.
- Qué ocurrió y qué debería haber ocurrido.
- Foto o captura opcional, sin información personal.

## Propuestas

Son bienvenidas ideas para niveles, accesibilidad, controles táctiles y mejoras de rendimiento. Antes de enviar código, abre un Issue con tu propuesta. Los términos de licencia para contribuciones se acordarán antes de aceptar cambios de código.

## English

Please include hardware model, app version, reproducible steps, actual vs expected behavior, and optionally a screenshot. Open an issue before making larger changes.
