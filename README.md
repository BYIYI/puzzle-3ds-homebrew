# Puzzle 3DS — videojuego homebrew para Nintendo 3DS

Juego de puzles para Old Nintendo 3DS, con campaña de 16 niveles, editor de mapas personalizados, guardado de partidas y controles físicos/táctiles.

## Estado del proyecto

- Versión actual de código: `puzzle-3ds-v07f-fix01`.
- Fix01 validado en hardware real: 12/12 pruebas funcionales.
- Este README se prepara en la rama de revisión de licencias, **no es una Release pública**.
- La versión descargable `.3dsx` y la visibilidad pública del repositorio se gestionarán en pasos separados.
