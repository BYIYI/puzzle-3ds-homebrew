# Nombre, logotipo e identidad de Puzzle 3DS (borrador)

La licencia propuesta para el código no concede permisos sobre nombres comerciales, logotipos, marcas o presentaciones que sugieran patrocinio o autoría oficial. No se afirma que «Puzzle 3DS» sea una marca registrada, exclusiva ni jurídicamente disponible: antes del lanzamiento se debe comprobar el uso de nombres similares.

## Principios propuestos
- Se puede describir de forma veraz que una obra deriva de o es compatible con Puzzle 3DS y citar el repositorio, sin sugerir respaldo oficial.
- No debe usarse el logotipo oficial, ni presentarse una versión modificada como «edición oficial», sin permiso de quien tenga derechos suficientes.
- El proyecto puede autorizar expresamente el uso de materiales promocionales para difundir una Release oficial.
- Todo fan art conserva los derechos de sus autores y está sujeto a derechos de terceros, si los hubiera.
- El nombre de Nintendo y de Nintendo 3DS se utiliza descriptivamente como referencia de compatibilidad. El proyecto es independiente y no está afiliado ni respaldado por Nintendo.

**No constituye registro de marca ni sustituye la verificación de derechos del nombre y logotipo.**
